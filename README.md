# 🌌 Easy Shader - AI Shader Generator

Easy Shader 是一款基于 C# WPF 和 DirectX 11 开发的现代化桌面渲染软件。它将 **LLM (大语言模型)** 与 **底层的图形渲染管道** 完美结合，让你只需通过自然语言描述，即可实时生成、编译并运行酷炫的 HLSL 特效。

## ✨ 核心特性 (Features)

- **🧠 AI 代码生成**：接入AI大模型，一键生成纯净的 HLSL 像素着色器代码。
- **⚡ 实时 DirectX 11 渲染**：无需依赖 Unity/UE 等大型引擎，毫秒级即时编译，底层硬件直接驱动。
- **👁️ 多模态视觉支持**：支持拖拽、Ctrl+V 粘贴图片素材，让 AI “看着图写特效”。
- **🔄 流式生成与并行对比**：打字机般的流畅体验，支持一次性生成多达 5 个方案并无缝切换。
- **📁 创意收藏夹**：一键无损截图并保存源码，构建你的私人 Shader 资产库。

## 🚀 快速体验 (Download)

**无需配置复杂的编程环境，开箱即用！**
1. 前往右侧的 [Releases](#) 页面。
2. 下载最新的 `Easy Shader 1.0.rar` 并解压。
3. 双击运行 `EasyShader.exe`。
4. 在右上角 ⚙️ 中填入你的 API Key，即可开始创作！
